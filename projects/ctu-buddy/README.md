# CTU Buddy

A lightweight, static portfolio version of CTU Buddy made with HTML and CSS. It includes an updated screenshot of the live site and a link to the interactive version.

## Files

- `index.html` — the CTU Buddy project page
- `styles.css` — responsive styling
- `assets/ctu-buddy-screenshot.jpg` — website screenshot
- `assets/favicon.svg` — project favicon

This is a portfolio showcase; posting and resource sharing happen on the live CTU Buddy website.

## Upload to GitHub

Upload the contents of this folder to the root of a GitHub repository. The root `index.html` is ready for GitHub Pages.
