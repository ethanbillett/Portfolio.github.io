# Ethan Billett — Portfolio Website Projects

A small static showcase of the **My Music** and **CTU Buddy** website projects. It is made with plain HTML and CSS so it can be uploaded to a GitHub repository and served with GitHub Pages.

## Files

- `index.html` — portfolio landing page with links to both projects.
- `my-music/index.html` — static project page and screenshot.
- `ctu-buddy/index.html` — static project page and screenshot.
- `styles.css` — shared responsive styles.
- `assets/` — both website screenshots and the favicon.

The showcase pages are static portfolio previews. The actual community features remain on the linked live websites.

## Put it on GitHub

Upload the contents of this folder to the root of a GitHub repository. The root `index.html` is the homepage; the relative links and image paths are set up for a project repository.
