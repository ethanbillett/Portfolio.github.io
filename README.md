# Ethan Billett — Portfolio

A responsive personal portfolio for Ethan Gareth Billett, built with plain HTML, CSS and JavaScript. No installation or build process required.

## Preview
Extract the ZIP, then open `index.html` in your browser. Keep all files and the `assets` folder together. For a local server, run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish to GitHub Pages
1. Copy the contents of this folder into the root of your website repository, replacing the matching files.
2. Commit and push the changes.
3. In the repository settings, open Pages and choose deployment from your website branch and root folder.
4. Open the URL GitHub provides once deployment completes.

All asset links are relative, so this also works in a repository subdirectory. Project cards open the supplied screenshots; live project URLs were not included in the original files.
